# ProgresDemo — Учебный проект

## Описание проекта

ProgresDemo — учебное приложение, разработанное на платформе .NET MAUI с использованием языка программирования C# и технологии XAML.

Проект объединяет два практических задания, демонстрирующих работу с вычислениями, асинхронными операциями, пользовательским интерфейсом и внешними API.

## Задание № 1. Вычисление определённого интеграла

Приложение выполняет численное вычисление интеграла функции sin(x) на заданном промежутке методом средних прямоугольников.

**Основные возможности:**
- Вычисление интеграла с использованием большого количества разбиений.
- Отображение прогресса выполнения вычислений.
- Возможность отмены длительной операции.
- Асинхронное выполнение вычислений, не блокирующее интерфейс.

## Задание № 2. Конвертер валют

Приложение позволяет получать официальные курсы валют Национального банка Республики Беларусь и выполнять конвертацию между BYN и иностранными валютами.

**Основные возможности:**
- Выбор даты получения курса.
- Получение официальных курсов через API НБРБ.
- Отображение курсов шести валют:
  - Российский рубль (RUB);
  - Евро (EUR);
  - Доллар США (USD);
  - Швейцарский франк (CHF);
  - Китайский юань (CNY);
  - Фунт стерлингов (GBP).
- Конвертация BYN в выбранную валюту.
- Обратная конвертация иностранной валюты в BYN.
- Проверка корректности введённых данных.

## Запуск проекта

1. Открыть файл решения `.sln` в Visual Studio 2022.
2. Установить необходимые компоненты .NET MAUI.
3. Выполнить восстановление NuGet-пакетов.
4. Выбрать целевую платформу запуска.
5. Запустить приложение.
